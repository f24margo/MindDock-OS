Модуль высокочастотного бэктестинга (HFT) для валидации и оптимизации параметров торговой стратегии `gaussian_mm` на секундных исторических данных (Asset: PEPE).

## 📊 Математическая концепция
Вместо классического пассивного маркет-мейкинга, симулятор использует концепцию **Elastic Spread (эластичного асимметричного спреда)** для защиты от инвентарного риска и токсичного потока ордеров (Toxic Flow):

1. **Gaussian Core:** 5 слоев кумулятивной гауссовой свертки через `scipy.signal.windows.gaussian` для фильтрации шума и определения математического центра тренда.
2. **Volatility Filter:** Адаптация спреда по индикатору `NATR` (Normalized ATR). Защитное отключение ордеров при `NATR > MAX_NATR` (импульсы, новости).
3. **Elasticity Modifiers:** Динамическое нелинейное расширение спреда со стороны накопленного инвентаря. При перекосе позиции в шорт, Ask-ордер экспоненциально удаляется, требуя от рынка повышенную премию за риск, а Bid поджимается ближе для эффективного откупа.
